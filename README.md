# Vale Verde — Minha Fazenda

Jogo de fazenda original, inspirado no gênero de simuladores rurais. Esta versão inicial roda no navegador e salva o progresso no armazenamento local do próprio navegador.

## Como jogar
1. Abra `index.html` no Chrome, Edge ou Opera.
2. Escolha uma semente na loja.
3. Clique em um terreno vazio para plantar.
4. Aguarde o tempo de crescimento e use **Colher**.
5. Venda os produtos no celeiro para ganhar moedas.
6. Compre galinhas e vacas para decorar sua propriedade.

## Salvamento e modo offline
- O progresso é salvo automaticamente no navegador via `localStorage`.
- Não usa login, Firebase, servidor remoto ou bibliotecas externas.
- Depois de abrir uma vez, o jogo funciona sem internet.
- Use sempre o mesmo navegador e não limpe os dados do site para preservar seu save.
- Esta é a primeira versão jogável; novos sistemas serão adicionados gradualmente.
